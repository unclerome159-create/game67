# Хроноакадемия

**Образовательная RPG-платформа для школьников**

Квесты по предметам · пошаговые бои с боссами · PvP-дуэли · достижения ·
кастомизация персонажей · кабинет учителя с ИИ-ассистентом

</div>

---

## Что это

«Хроноакадемия» превращает школьные предметы в четыре стихии игрового мира:

| Стихия  | Предмет                        | Класс персонажа |
| ------- | ------------------------------ | --------------- |
| Хронос  | Математика                     | Математик       |
| Эфир    | Лингвистика и русский язык     | Лингвист        |
| Терра   | История                        | Историк         |
| Вольта  | Физика                         | Физик           |

Ученик проходит квесты по карте миров, сражается с боссами в пошаговых боях,
участвует в PvP-дуэлях, качает персонажа и открывает достижения. Учитель
собирает вопросы и квесты в своём кабинете — вручную или через ИИ-ассистента,
который генерирует задания по теме, загруженному файлу или учебному тексту.

## Стек

- **React 19** + **TypeScript**
- **Vite 8** (`@vitejs/plugin-react`)
- **Tailwind CSS 4** (через `@tailwindcss/vite`)
- **Express 4** — сервер и API
- **Google GenAI SDK** — генерация учебных вопросов (Gemini)
- **Bun** — пакетный менеджер и рантайм (см. `bun.lock`)

## Быстрый старт

Нужен [Bun](https://bun.sh) ≥ 1.2 и Node.js ≥ 20 (для продакшн-сборки не обязателен).

```bash
bun install
cp .env.example .env      # затем впишите свой GEMINI_API_KEY
bun run dev
```

Приложение поднимется на <http://localhost:3000>.

Если Bun не установлен, проект можно запустить и через Node:

```bash
npm install
npm run dev
```

## Переменные окружения

| Переменная       | Обязательна | Назначение                                                     |
| ---------------- | ----------- | -------------------------------------------------------------- |
| `GEMINI_API_KEY` | для ИИ      | Ключ Gemini API для генерации вопросов в кабинете учителя       |
| `APP_URL`        | нет         | Публичный адрес приложения                                      |
| `PORT`           | нет         | Порт сервера, по умолчанию `3000`                              |

Без `GEMINI_API_KEY` приложение работает: недоступен будет только ИИ-генератор
вопросов, остальные разделы (карта, арена, персонаж, архитектура) полностью
функциональны.

## Скрипты

| Команда           | Что делает                                            |
| ----------------- | ----------------------------------------------------- |
| `bun run dev`     | Dev-сервер (Express + Vite middleware) с HMR          |
| `bun run build`   | Продакшн-сборка клиента в `dist/`                     |
| `bun run start`   | Запуск сервера без сборки                             |
| `bun run lint`    | Проверка типов (`tsc --noEmit`)                       |
| `bun run preview` | Предпросмотр собранного бандла                        |

## Docker

Готовый образ собирает клиент и запускает сервер под Bun.

```bash
# прод-подобный запуск
docker compose up --build app

# режим разработки с горячей перезагрузкой
docker compose --profile dev up dev
```

Или напрямую:

```bash
docker build -t chronoacademy .
docker run --rm -p 3000:3000 -e GEMINI_API_KEY="$GEMINI_API_KEY" chronoacademy
```

`GEMINI_API_KEY` не зашивается в образ — передавайте его через `--env-file .env`
или переменную окружения.

## Структура проекта

```
server.ts                      Express-сервер + API /api/ai/generate-questions
src/
  App.tsx                      корневой компонент, навигация и состояние профиля
  main.tsx                     точка входа React
  index.css                    подключение Tailwind
  types/game.ts                доменные типы (профиль, квесты, боссы, ИИ-вопросы)
  data/gameData.ts             стартовый контент: вопросы, квесты, стихии, достижения
  components/
    WorldMapView.tsx           карта миров и прохождение квестов
    BattleArenaView.tsx        арена: PvE-боссы и PvP-дуэли
    BattleCanvas.tsx           отрисовка сцены боя
    CharacterStudioView.tsx    профиль, гардероб, достижения
    CharacterAvatar.tsx        отрисовка аватара персонажа
    TeacherCabinetView.tsx     кабинет учителя и ИИ-генератор вопросов
    PlatformArchitectureView.tsx  описание архитектуры платформы
  utils/sound.ts               звуковые эффекты
```

Прогресс игрока сохраняется в `localStorage` под ключом
`chronoacademy_state_v1`; сброс — кнопка в разделе «Персонаж».
